# Data Cleaning and Preparation

## Project Overview
This project focuses on identifying and resolving data quality issues in an e-commerce sales dataset using Python and Pandas.

## Objectives
- Identify missing values.
- Detect and remove duplicate records.
- Identify incorrect data types.
- Detect and correct inconsistent values.
- Generate a cleaned dataset for further analysis.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Google Colab

## Project Files
- `Ecommerce sales.zip` – Original dataset.
- `Data_Cleaning_&_Preparation.ipynb` – Python notebook containing the data cleaning process.
- `cleaned_dataset.csv` – Final cleaned dataset.

## Data Cleaning Steps
1. Loaded and explored the original dataset.
2. Identified missing values.
3. Detected duplicate records.
4. Checked and corrected data types.
5. Standardized inconsistent values.
6. Removed duplicate records and handled missing values.
7. Exported the cleaned dataset as a CSV file.
